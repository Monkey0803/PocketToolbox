# 随身工具箱 / Pocket Toolbox

HarmonyOS NEXT ArkTS 离线工具应用，面向手机、平板和折叠屏（含阔直板、阔折叠、三折叠），现有 **31 个工具**，界面中英双语，工具数据只存本机。

## 现有工具

工具按 6 个固定分类分段浏览（声明了未登记分类的工具统一落到兜底的「其他」段，正常恒为空）：

- **扫码与图像**
  - 二维码生成——支持文本、网址、WiFi、名片、电话、短信、邮件、位置八种内容模板，可设容错等级与码色，含**自定义码色（可拉系统取色器取色）与居中 Logo（从相册选图，本机合成，仅容错 Q/H）**；
  - 条形码生成——十二种码制：Code 128、Code 39、Code 93、EAN-13、EAN-8、UPC-A、UPC-E、ITF-14、Codabar，以及 Data Matrix、PDF417、Aztec 三种二维码制；结果可主动保存为文件或保存到系统相册；
  - 系统扫码与**从相册图片识别**条码/二维码；
  - 文档扫描——用系统扫描控件生成 JPG/PDF，可设默认滤镜与拍摄方式、逐页删除、继续追加扫描、把 JPG 存进相册，并可**在本机提取图片文字**（端侧识别、不联网，结果可复制或直接送进文本工具）；
  - **图片工具**——从相册选一张图，在本机**压缩（画质档）、改尺寸（整幅/75%/50%/25%/指定最长边）、旋转与水平垂直翻转、转换格式（JPEG/PNG/WebP）**，结果照实给出压缩前后体积对比并保存到相册或分享；图片只在本机内存与缓存里处理，不上传、不写历史；
  - **证件照**——详见下文「[证件照](#证件照)」。
- **计算与财务**
  - 折扣与均摊——五种类型：折扣计算（含**立减叠加与等效折扣**）、折扣反推、百分比计算（含求占比/增减/变化）、**加价与毛利率定价**、账单均摊与小费，各结果可一键复制；
  - 个税估算——居民个人工资个税/稿酬/离职补偿/劳务报酬/特许权使用费，含**年终奖单独计税**与临界点提示，以及**年度综合所得汇算**（全年收入 − 60000 − 三险一金 − 专项附加扣除 − 其他扣除，按同一张年度税率表算出应补/应退；扣除上限在登记表里，超限部分不计入并如实提示）；
  - **贷款计算（等额本息/等额本金，另有按月复利、可加每月定投的「复利/储蓄」估算）**；
  - **健康计算（BMI/基础代谢/每日消耗估算）**；
  - **科学计算器（表达式求值：可省写乘号、阶乘、30 个函数、DEG/RAD、可选有效位数）**；
  - **金额大写**——把数字金额转成人民币中文大写与英文读法，并给出千分位小写；支持「元/角/分」与「整」的规范写法（元位为零且只有角/分时省略「零元」），最大 999,999,999,999.99；换算只在本机进行。
- **文本与编码**
  - 文本统计与整理——去空行/去重/排序/大小写，以及 Base64、MD5/SHA-1/SHA-256 摘要与**摩尔斯编码/解码**，还有 **JSON 格式化 / 压缩为一行 / 校验**（令牌级扫描：只校验语法并重新排版，`1.0`、`1e10`、大整数与重复键都**原样保留**，出错时在结果卡给出**行列号**与原因）、**繁简转换**（随包 OpenCC 字表、词组优先；只做通用规范字形，不做地区用词）与**命名风格转换**（驼峰 / 大驼峰 / 下划线 / 短横线 / 常量式）；
  - **URL 编解码**——四种方式（组件 / 整串网址 / 表单 / 自定义保留字符）、**同一屏同时给出编码与解码结果**，并把网址里的**查询参数逐条拆开**（名字与值都解码，解不开的片段标红并原样保留，不静默吞掉）；全部本机计算；
  - 密码生成——完整密码、**PIN 码**与**口令短语**，结果附**强度预估**分级（口令短语的强度只取决于词数，分隔符不增加熵；词表是随包的 EFF large wordlist，CC-BY 4.0 署名见设置页「第三方软件与数据许可」）；可关掉「排除易混字符」、可一次生成 **1/2/3/5/10 条**逐条复制；另有**「强度检查」**——把你已有的密码粘进来，只在本机内存里看长度、字符类别与常见弱口令特征，不落盘、不查泄露库；
  - **进制与位运算**——方式下拉切换「进制换算」与「位运算」：前者在 2/8/10/16/32/36 进制间互转，后者是 32 位无符号运算（含按位与/或/异或/取反、左移/逻辑右移与循环移位），结果同时给出十进制、有符号 int32、十六进制、二进制及大端/小端字节视图，每一行都能一键复制；
  - **文本对比**——逐行差异，单侧上限 600 行，可复制 unified 文本。
- **时间与日期**
  - 多倒计时与秒表——时长预设、重复计时、秒表计次含最快/最慢；另有**番茄钟**：专注/短休/长休三阶段（每 4 个专注阶段一次长休）、时长可调、可开自动进入下一阶段（**应用在前台时**；在后台阶段结束由系统本地通知提醒，自动开始回到应用后接着进行），到点有应用内提示、触觉与系统本地提醒；
  - 日期间隔与加减天数——含**时间点差值**，按墙上时间逐字段计算；
  - 时间戳——与本地/UTC 互转，并可按常用时区换算（本机、17 个城市，另有 UTC 固定偏移条目）；**每行一条即可批量转换**（上限 200 行，逐行给出结果或错误原因，超出上限如实提示只转换了前 N 行）；
  - **纪念日**——多条清单本机保存、支持每年重复、按临近排序。
- **生活与换算**
  - 二十一类单位换算——含市制斤两尺寸里亩、压力/能量/功率/角度/频率/油耗、**数据速率 / 力 / 扭矩 / 照度 / 剂量当量 / 加速度**，以及**货币**（按你主动触发的汇率更新换算）；可切换有效位数并列出同类其他单位；
  - 随机整数与骰子、硬币、名单抽取/随机排序/分组，以及**转盘抽奖**（扇区角度按权重分配，先抽结果再转到它，可复制结果）；
  - **颜色工具（HEX/RGB/HSL 互转与 WCAG 对比度检查）**；
  - **亲戚称呼**——输入或点选亲属关系链给出称谓、辈分与关系说明，常见关系直接给名词、远亲与姻亲给关系描述；
  - **身份证校验**——校验 18 位身份证号（15 位旧号自动升位）的格式与校验位、生日是否真实存在，并按号码给出出生日期、性别、年龄与**按前两位的省份参考**；同一页可校验银行卡号的长度与 Luhn 校验位并**参考识别卡组织**。**支持扫描**：拍照或从相册选图，在本机用端侧文字识别把证件上的号码**自动填进输入框**（校验位不符时也会填入并提示核对）——不需要相机权限，照片只写进应用缓存、识别完立即删除，不进相册、不上传。号码只在本机内存里校验，不保存、不进历史、不进日志；身份证离线无法判断真伪，卡组织也可能认错，页面都如实说明。
- **系统与设备**
  - 手电筒——常亮与四档亮度、国际求救信号 SOS 等**求援灯语**、任意字母数字的**摩尔斯灯语**、1–5 Hz 频闪、定时关闭与屏幕常亮，以及把整屏当柔光板的**屏幕补光**；
  - 水平仪和**指南针**——读取方向传感器显示方位角与十六方位，盘面随朝向旋转、顶部三角指示手机顶部所指方向，倾斜与磁场干扰时给出提示；
  - **网络工具**——DNS 域名解析、端口连通、HTTP 状态与响应头、网址分解、**链接信息与短链展开**，五种方式均需你显式触发；
  - **网络查询**——IP 归属地与域名 WHOIS（RDAP）、**TLS 证书查看**（主题/颁发者/有效期/SAN/协议版本与密码套件），并如实区分「系统信任校验通过 / 未通过 / 未校验」；
  - **世界时钟**——同屏对照本机与最多 12 个城市的时间，带当地日期、与本机的日差与快慢、白天/夜间标注；偏移由系统给出（含夏令时），设备不支持某时区时如实说明而不显示 0，城市清单只存本机。

外壳能力：**本地历史记录**（二维码生成与扫码，加上文本、换算、时间戳、折扣与均摊的复制结果，可按类别筛选、按关键字搜索、删除当前筛选结果，点条目可跳回对应工具并回填内容）、**工具搜索**、**中英双语界面**与**工具收藏**（按收藏顺序排列，最近收藏在前；长按收藏卡片可置顶或取消收藏，也可进入排序模式拖拽调整顺序）。底部「工具 / 收藏 / 设置」三个 Tab 分别展示全部工具、已收藏工具与应用设置；在工具卡片上点击星标即可收藏或取消收藏，并保存在本机。

竞品差距、需新增/需优化/需深挖的能力与分期路线见 [竞品对比与演进路线](docs/COMPETITIVE_ANALYSIS.md)。

## 界面与自适应

界面颜色已**资源化**（`resources/base/element/color.json` 与 `resources/dark/element/color.json`），因此**跟随系统深色模式**：系统切到深色时由 ArkUI 资源系统自动重解析并刷新，应用不需要自己判断主题。

界面布局**按官方断点自适应**（宽度 XS/SM/MD/LG/XL 与高宽比断点）：工具网格列数 1 / 2 / 3 / 4 / 5 随窗口宽度变化，内容列按断点取 920 / 1080 / 1200 vp，矮而宽的形态（阔折叠展开、三折叠全展开、平板横屏）自动收紧纵向留白；展开/折叠时不重启应用即时重排。工具页与收藏页各自的**「每行显示」**可在页顶从「自动」改成固定档位（两页互不影响，可选项按当前窗口收窄，卡片宽度始终 ≥ 150 vp）。口径与各形态实测值见 [`docs/DEVICE_ACCEPTANCE.md`](docs/DEVICE_ACCEPTANCE.md) 第 27 节。

**工具页按分类分段浏览 + 增强搜索**（2026-10-22，26 个工具）：工具按 6 个固定分类（扫码与图像 / 计算与财务 / 文本与编码 / 时间与日期 / 生活与换算 / 系统与设备）分段显示，页顶「分类」下拉可只看一类并把选择记住；搜索除中英标题与别名外还认**拼音首字母**（`ewm` → 二维码、`sjc` → 时间戳），结果按「精确 > 前缀 > 子串 > 分类名」分级排序，分类名本身也能搜（搜「时间」一次列出全部时间类工具）；顶部的「最近使用」快捷入口保留。分类与列数一样只保存在本机、不含任何输入内容（见 [`docs/DEVICE_ACCEPTANCE.md`](docs/DEVICE_ACCEPTANCE.md) 第 33 节）。

界面语言可在**跟随系统**、简体中文与 English 之间切换（默认「跟随系统」：取系统/应用的当前语言，取不到时用中文；旧版本存的 zh/en 偏好仍然有效）。

设置页可在默认图标与四款现有概念图之间切换桌面图标（图标选择是**只显示图标、不显示名称**的缩略图网格，名称只保留在屏幕朗读文本里）。此功能使用 API 26 的系统备选图标能力；当前选择由系统管理，应用不另存图标偏好。**主题色**（2026-10-23 新增）同样在设置页：可选「经典蓝 / 青碧 / 松绿 / 紫罗兰 / 玫红 / 靛蓝 / 石墨」7 套预设，或点色轮用系统取色面板挑任意颜色；只换**强调色**（按钮、图标、选中态、页签选中图标），成功/警告/危险等状态色与每个工具的卡片底色不变，浅色与深色各一套取值、切换立即全局生效，颜色会自动夹取到可读的对比度区间（挑浅色也不会看不清）。偏好键 `theme_color` / `theme_custom_hex` 只存外观选择，不含任何输入内容。桌面长按应用图标还可用四个快捷方式（生成二维码 / 生成条形码 / 科学计算器 / 计时与秒表）直达对应工具页，也可以从「卡片」入口添加**「常用工具」服务卡片**（2×2 / 2×4 / 4×4）：格子内容**收藏优先**（没有收藏时显示二维码、单位换算、计时、折扣与均摊四个默认工具），点一格直达对应工具页；应用内改收藏或切语言后会主动推送刷新，系统也每 30 分钟兜底刷新。卡片只读取本机的收藏与语言偏好，不申请任何权限、不联网。设置页还显示本机**设备信息**（设备型号、系统版本、API 版本、应用版本、设备类型），只在本机读取、不写存储、不联网，也不申请任何权限。设置页「关于」里还有两段**随包、离线可读**的正文：**隐私政策全文**与**第三方软件与数据许可**（词表/字表/历算数据的来源与许可逐条列出，不需要联网）。

## 联网与本地提醒

**联网能力扩展 + 设置页「联网」区块 + 纪念日本地提醒**（2026-10-22，26 个工具）：把联网从「恰好三处」改成**登记表驱动 + 统一门控**（`model/NetPolicy.ets` 的 `NET_ACTIONS` + `services/NetGate.ets`），**不新增任何权限**。新增三个可联网能力：

1. **网络工具**加第 5 种方式「**链接信息**」——跟随跳转读网页标题/描述/站点名；**短链展开**就是它的特例：系统 HTTP 响应没有「最终 URL」字段，因此由应用自己按 `Location` 头最多跟 5 跳，并会拦住循环跳转；
2. **网络查询**（新工具卡）——**IP 归属地与域名 WHOIS** 走公开的 RDAP 引导服务；**TLS 证书查看**与本机做两次握手（一次正常校验、一次跳过校验把证书读出来），**绝不说「读到了内容」＝「证书可信」**；
3. **节气与农历节日数据包**——构建期由 MIT 许可的历算库生成随包数据（见 [`docs/THIRD_PARTY_NOTICES.md`](docs/THIRD_PARTY_NOTICES.md)），日期计算的「农历」方式据此显示当天节气与传统节日、覆盖年份与数据时间，设置页可在线更新。

设置页新增「**联网**」区块：**总开关 + 逐项开关（由登记表驱动，加一个动作就自动多一行）+「仅 Wi-Fi」+ 清除联网缓存**，每项下面写明「这个动作会把什么发到哪里」；被挡下时如实说明原因。**纪念日**每条可开启**本地提醒**（`reminderAgent` 的 calendar reminder，用 `repeatMonths`+`repeatDays` 实现每年重复，到当天 09:00），删除/清空/清数据都会取消本机通知——**全程不联网、不新增权限**。

## 证件照

（2026-10-22 新工具）从相册选一张人像，按标准规格（一寸 / 小一寸 / 大一寸 / 二寸 / 小二寸 / 大二寸 / 护照 / 美国签证 / 身份证 / 驾驶证 / 社保卡 / 港澳通行证，另有自定义毫米）拖拽、双指缩放取景，可一键用**端侧人脸检测**自动构图；按所选底色（白 / 蓝 / 红 / 浅灰 / 原底色）用**端侧主体抠图**换底，输出 300 dpi 的精确像素（如一寸 `295 × 413 px`），也可拼到 5 寸 / 6 寸相纸（自动选横竖、带裁切参考线）后保存到相册或分享。**全程在本机完成、不联网、不新增权限**；设备不提供端侧抠图/人脸检测时如实降级（保留原底色、请手动取景），不会用色块糊住人像。口径与验收项见 [`AGENTS.md`](AGENTS.md) 与 [`docs/PHONE_ACCEPTANCE_CHECKLIST.md`](docs/PHONE_ACCEPTANCE_CHECKLIST.md)。

## 数据与隐私

个税结果为本机计算的估算，不是申报结果。工资采用累计预扣，支持填写此前累计额、个人社保/公积金实缴额或基数与比例、专项附加扣除和个人养老金；**社保与公积金可以存成本机预设**（只存比例与可选基数，不存收入或税额；可改名、逐条删除，随包只有一条标注「非权威」的示例）下次一键套用。劳务报酬和特许权使用费支持税后反推。**年度汇算**按全年口径估算应补/应退，与工资累计预扣**共用同一张年度税率表与速算扣除数**；专项附加扣除的上限写在纯逻辑登记表里（子女教育与婴幼儿照护按人数翻倍、赡养老人区分独生与非独生分摊），超出上限的部分不计入并会如实提示。各地参数与扣除口径由用户根据官方信息核对（页面显示按哪天的规则算）。大病医疗只按 80000 元封顶、不判断 15000 元门槛。页面上的官方链接仅在用户主动点击时由系统打开，工资及扣除数据不会发送给第三方。

个税、条形码、计算、日期、文本、随机选择、密码、亲戚称呼、进制与位运算、文本对比、网络工具、文档扫描、**金额大写**、**身份证与银行卡号校验**和**图片工具**的输入和结果不会写入应用持久存储（纪念日清单、汇率缓存、世界时钟的城市清单、番茄钟的设置与进度、图片工具的上次选项保存在本机；单位换算只记住上次的类别、单位与精度，不含输入值；秒表、计次记录与历史记录保存在本机）；扫描文件可由用户主动导出。**身份证号与银行卡号只在本机内存里校验，图片只在本机内存与缓存里处理**——两者都不写入存储、不进历史记录、不上传；**证件扫描的那张照片只写进应用缓存并在识别后立即删除**（不进相册）。

离线工具完整可用；联网能力（网络工具与链接信息、网络查询、汇率更新、节假日数据更新、节气数据包更新、应用内更新检查）只在你显式触发时发起请求，不会在启动或后台联网，并且在设置页的「联网」区块里**逐项可关**（含总开关与「仅 Wi-Fi」；关掉后界面会说明原因，而不是「点了没反应」）；纪念日与倒计时的提醒由系统本地通知发出，不需要联网。设置页可以清空历史记录，也可以在你主动点「检查更新」时拉取节假日数据（校验或网络失败一律保留随包数据）。

## 开发构建

使用 DevEco Studio API 26 打开此目录。

首次复制 `build-profile.example.json5` 为 `build-profile.json5`；后者是本机签名配置文件，已加入 `.gitignore`。

推荐用仓库里的构建辅助（Windows / macOS 通用，自动定位 DevEco 的 SDK、JBR 与 hvigorw，并把 `JAVA_HOME\bin` 前置进 PATH、给 JVM 加堆上限）：

```sh
node tools/build-hap.mjs          # = assembleHap --mode module -p product=default
node tools/build-hap.mjs --tests  # 构建后顺带跑纯逻辑单测
node tools/build-hap.mjs --release # 发布包：加 -p buildMode=release（不含 source map）
```

> **发布必须用 `--release`**（2026-10-29 实测）：调试构建会把 ArkTS 的 `ets/sourceMaps.map` **原样存储**（不压缩、2.25 MiB）打进 HAP，`ets/modules.abc` 也带调试信息——同一份源码 **debug 9.36 MiB vs release 5.36 MiB**。「外置 source map」的构建配置路子只能**另存一份**、包里那份仍在，命令行 `-p` 更是完全不生效，**只有 release 模式真的去掉它**（三条路子的实测记录见 [`docs/RELEASE_CHECKLIST.md`](docs/RELEASE_CHECKLIST.md)），因此不改配置、直接用 release 模式构建。

也可以自己配好环境后直接调 hvigorw：

```sh
export DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk
export JAVA_HOME=/Applications/DevEco-Studio.app/Contents/jbr/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
/Applications/DevEco-Studio.app/Contents/tools/hvigor/bin/hvigorw assembleHap --mode module -p product=default
```

两个本机实测过的环境坑（`node tools/build-hap.mjs` 已代劳）：只设 `JAVA_HOME`、不把它的 `bin` 加进 PATH 时，打包阶段会报 `spawn java ENOENT`（hvigor 守护进程还会继承旧环境，故辅助脚本默认 `--no-daemon`）；同时开模拟器时页面文件紧张，JVM 默认提交量会让打包报 `页面文件太小`。辅助脚本因此**分开设两个上限**：hvigor 自己的 JVM 用 512 MB（源码涨到 30 个工具后 256 MB 会让 ArkTS 编译报 `Zone Allocation failed`），`PackageHap`/`SignHap` 这些派生工具 JVM 用 ≤ 256 MB（给多了它们会因页面文件不足报 `00308018 / Tools execution failed`）；`--xmx <MB>` 可整体覆盖。

纯逻辑验证：`node --disable-warning=ExperimentalWarning tests/run-unit-tests.mjs`（本机 Node.js 26）。本机 DevEco Studio 已生成调试签名，调试 HAP 可用于真机安装；发布包仍需正式包名与发布签名。
