# 随身工具箱 / Pocket Toolbox

HarmonyOS NEXT ArkTS 离线工具应用，面向手机、平板和折叠屏（含阔直板、阔折叠、三折叠）。现有二维码（支持文本、网址、WiFi、名片、电话、短信、邮件、位置八种内容模板，可设容错等级与码色）与条形码生成（十二种码制：Code 128、Code 39、Code 93、EAN-13、EAN-8、UPC-A、UPC-E、ITF-14、Codabar，以及 Data Matrix、PDF417、Aztec 三种二维码制）、系统扫码与**从相册图片识别**条码/二维码、折扣与均摊计算（五种类型：折扣计算含**立减叠加与等效折扣**、折扣反推、百分比计算含求占比/增减/变化、**加价与毛利率定价**、账单均摊与小费，各结果可一键复制）、居民个人工资个税/稿酬/离职补偿/劳务报酬/特许权使用费估算、**贷款计算（等额本息/等额本金）**、**颜色工具（HEX/RGB/HSL 互转与 WCAG 对比度检查）**、**健康计算（BMI/基础代谢/每日消耗估算）**、**科学计算器（表达式求值：可省写乘号、阶乘、30 个函数、DEG/RAD、可选有效位数）**、十四类单位换算（含市制斤两尺寸里亩、压力/能量/功率/角度/频率/油耗，可切换有效位数并列出同类其他单位）、多倒计时与秒表（时长预设、重复计时、秒表计次含最快/最慢）、手电筒（常亮与四档亮度、国际求救信号 SOS 等**求援灯语**、任意字母数字的**摩尔斯灯语**、1–5 Hz 频闪、定时关闭与屏幕常亮，以及把整屏当柔光板的**屏幕补光**）、日期间隔与加减天数、时间戳与本地/UTC 互转并可按 18 个常用时区换算、文本统计与整理（去空行/去重/排序/大小写，以及 Base64、URL 编解码与 MD5/SHA-1/SHA-256 摘要）、随机整数与骰子、硬币、名单抽取/随机排序/分组、密码生成、文档扫描、水平仪和**指南针**（读取方向传感器显示方位角与十六方位，盘面随朝向旋转、顶部三角指示手机顶部所指方向，倾斜与磁场干扰时给出提示）、**亲戚称呼（输入或点选亲属关系链给出称谓、辈分与关系说明，常见关系直接给名词、远亲与姻亲给关系描述）**，以及**本地历史记录**（二维码生成与扫码，加上文本、换算、时间戳、折扣与均摊的复制结果，可按类别筛选、按关键字搜索、删除当前筛选结果，点条目可跳回对应工具并回填内容）、工具搜索、中英双语界面和工具收藏（按收藏顺序排列，最近收藏在前；长按收藏卡片可置顶或取消收藏，也可进入排序模式拖拽调整顺序）。底部“工具、收藏、设置”三个 Tab 分别展示全部工具、已收藏工具和应用设置；在工具卡片上点击星标即可收藏或取消收藏，并保存在本机。设置页可以清空历史记录。条形码可主动保存为文件或保存到系统相册。个税、条形码、计算、日期、文本、随机选择、密码、亲戚称呼与文档扫描的输入和结果不会写入应用持久存储（单位换算只记住上次的类别、单位与精度，不含输入值；秒表、计次记录与历史记录保存在本机）；扫描文件可由用户主动导出。

竞品差距、需新增/需优化/需深挖的能力与分期路线见 [竞品对比与演进路线](docs/COMPETITIVE_ANALYSIS.md)。

界面颜色已**资源化**（`resources/base/element/color.json` 与 `resources/dark/element/color.json`），因此**跟随系统深色模式**：系统切到深色时由 ArkUI 资源系统自动重解析并刷新，应用不需要自己判断主题。

界面布局**按官方断点自适应**（宽度 XS/SM/MD/LG/XL 与高宽比断点）：工具网格列数 1 / 2 / 3 / 4 / 5 随窗口宽度变化，内容列按断点取 920 / 1080 / 1200 vp，矮而宽的形态（阔折叠展开、三折叠全展开、平板横屏）自动收紧纵向留白；展开/折叠时不重启应用即时重排。口径与各形态实测值见 [`docs/DEVICE_ACCEPTANCE.md`](docs/DEVICE_ACCEPTANCE.md) 第 27 节。

界面语言可在**跟随系统**、简体中文与 English 之间切换（默认「跟随系统」：取系统/应用的当前语言，取不到时用中文；旧版本存的 zh/en 偏好仍然有效）。

设置页可在默认图标与四款现有概念图之间切换桌面图标（图标选择是**只显示图标、不显示名称**的缩略图网格，名称只保留在屏幕朗读文本里）。此功能使用 API 26 的系统备选图标能力；当前选择由系统管理，应用不另存图标偏好。桌面长按应用图标还可用四个快捷方式（生成二维码 / 生成条形码 / 科学计算器 / 计时与秒表）直达对应工具页，也可以从「卡片」入口添加**「常用工具」服务卡片**（2×2 / 2×4 / 4×4）：格子内容**收藏优先**（没有收藏时显示二维码、单位换算、计时、折扣与均摊四个默认工具），点一格直达对应工具页；应用内改收藏或切语言后会主动推送刷新，系统也每 30 分钟兜底刷新。卡片只读取本机的收藏与语言偏好，不申请任何权限、不联网。设置页还显示本机**设备信息**（设备型号、系统版本、API 版本、应用版本、设备类型），只在本机读取、不写存储、不联网，也不申请任何权限。

个税结果为本机计算的预扣估算。工资采用累计预扣，支持填写此前累计额、个人社保/公积金实缴额或基数与比例、专项附加扣除和个人养老金；各地参数由用户根据官方信息核对。劳务报酬和特许权使用费支持税后反推。大病医疗与年度综合所得汇算不在计算范围内。页面上的官方链接仅在用户主动点击时由系统打开，工资及扣除数据不会发送给第三方。

## 开发构建

使用 DevEco Studio API 26 打开此目录。

首次复制 `build-profile.example.json5` 为 `build-profile.json5`；后者是本机签名配置文件，已加入 `.gitignore`。

推荐用仓库里的构建辅助（Windows / macOS 通用，自动定位 DevEco 的 SDK、JBR 与 hvigorw，并把 `JAVA_HOME\bin` 前置进 PATH、给 JVM 加堆上限）：

```sh
node tools/build-hap.mjs          # = assembleHap --mode module -p product=default
node tools/build-hap.mjs --tests  # 构建后顺带跑纯逻辑单测
```

也可以自己配好环境后直接调 hvigorw：

```sh
export DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk
export JAVA_HOME=/Applications/DevEco-Studio.app/Contents/jbr/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
/Applications/DevEco-Studio.app/Contents/tools/hvigor/bin/hvigorw assembleHap --mode module -p product=default
```

两个本机实测过的环境坑（`node tools/build-hap.mjs` 已代劳）：只设 `JAVA_HOME`、不把它的 `bin` 加进 PATH 时，打包阶段会报 `spawn java ENOENT`（hvigor 守护进程还会继承旧环境，故辅助脚本默认 `--no-daemon`）；同时开模拟器时页面文件紧张，JVM 默认提交量会让打包报 `页面文件太小`，辅助脚本默认把堆上限收到 256 MB（`--xmx <MB>` 可放开）。

纯逻辑验证：`node --disable-warning=ExperimentalWarning tests/run-unit-tests.mjs`（本机 Node.js 26）。本机 DevEco Studio 已生成调试签名，调试 HAP 可用于真机安装；发布包仍需正式包名与发布签名。
