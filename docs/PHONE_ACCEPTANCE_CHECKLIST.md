# 真机验收清单（一页版，可勾选）

> 用途：把**还没在真机上跑过**的验收项集中到一页，插上 PLR-AL00（或同形态真机）后按顺序走一遍，通过就打勾。
> 逐条步骤与更细的现象描述仍在 [`DEVICE_ACCEPTANCE.md`](DEVICE_ACCEPTANCE.md)（每项后面标注了章节号）。
> 模拟器能做的（交互、刷新、文案、坐标）都已在 `DEVICE_ACCEPTANCE.md` 里标为「模拟器已通过」，这里只列**必须真机**的项。

## 0. 环境与命令

```powershell
$hdc = "C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe"
$t   = "<真机 key，hdc list targets 里那条非 127.0.0.1:5555 的>"
& $hdc -t $t install -r entry/build/default/outputs/default/entry-default-signed.hap   # 升级安装，保留数据
& $hdc -t $t shell aa force-stop com.example.pockettoolbox
& $hdc -t $t shell aa start -a EntryAbility -b com.example.pockettoolbox --ps tool qr  # 直达某个工具页
& $hdc -t $t shell uitest dumpLayout -p /data/local/tmp/l.json                          # 读控件文本与 bounds
& $hdc -t $t file recv /data/local/tmp/l.json .cache/l.json
& $hdc -t $t shell snapshot_display -f /data/local/tmp/x.jpeg                           # 截图
& $hdc -t $t file recv /data/local/tmp/x.jpeg docs/screenshots/phone/<名字>.jpeg
& $hdc -t $t shell uitest uiInput click <x> <y>                                         # 点按（坐标与截图同尺度）
```

真机 PLR-AL00 的密度是 3x：**48 vp = 143 px、44 vp = 131 px、56 vp = 167 px、144 vp = 428 px**（用 `dumpLayout` 的 `bounds` 反推可点区域是否达标）。

## 1. 本轮「图标按钮去底色」（对应第 26 节）

已在 PLR-AL00 通过的部分：20 个工具页逐页 `dumpLayout`（标题与按钮尺寸全对）、二维码页观感、随机选择/个税文字按钮、收藏页排序开关、手电筒 144 vp、计时页操作行。
剩下这三项需要人工：

- [ ] **屏幕朗读**：设置 → 辅助功能 → 屏幕朗读打开，逐个念 57 处图标按钮（中文一遍、切 English 再一遍）。重点：二维码四枚（生成/扫码/相册/历史）、结果行复制、计时页暂停/计次/重置、收藏页排序开关。
- [ ] **系统深色模式**：系统切深色 → 回到应用，逐页看彩色图标（蓝 `#4C8DF6`、绿 `#35B08A`、紫 `#9B85E0`、橙 `#E8A33D`、灰）在深底上的对比度；重点看浅色下偏淡的 `textMuted` 重置图标与「计次」禁用态。
- [ ] **宽屏 / 折叠屏**：展开折叠屏或平板，确认操作行仍是同一行、不换行、间距一致；单位换算页「交换单位」已由 40 vp 提到 44 vp，看是否挤压标签。

## 2. 其它仍未在真机跑过的功能项

### 2.1 服务卡片「常用工具」（第 22 节）
- [ ] 桌面长按应用图标出现「卡片」入口；卡片中心名称为「随身工具箱」、卡片名「常用工具」。
- [ ] 「添加至桌面」成功后：2×2 显示 4 格（无收藏时为 二维码 / 单位换算 / 计时 / 折扣与均摊）。
- [ ] 点「二维码」格 → 直达二维码页（不是停在工具首页）；点卡片空白处 → 只打开应用首页。
- [ ] 应用内收藏「健康计算」后回桌面 → 卡片首格变成「健康计算」（主动刷新）；不支持主动刷新的设备最多等 30 分钟。
- [ ] 切 English → 卡片标题与格子文字变英文；系统深色 → 卡片底色跟随。
- [ ] 删除卡片再重新添加、以及 `hdc install -r` 升级安装后，卡片不空白。

### 2.2 桌面长按快捷方式（第 20 节）
- [ ] 长按图标应出现 4 个快捷方式（生成二维码 / 生成条形码 / 科学计算器 / 计时与秒表），英文环境为 `Create a QR code` 等。
- [ ] 逐个点击：直接进入对应工具页（标题栏是工具名、底部页签隐藏）。
- [ ] 冷启动与热启动（应用已在后台）都试；从快捷方式进入后按返回，再正常启动应用**不应**自动跳回上次的快捷方式目标。

### 2.3 代理提醒与倒计时（发布检查表「尚未验收」段）
- [ ] 计时器到期提醒：应用在后台、以及**进程结束**后都要试（需先申请/开通代理提醒权益）；通知被拒绝时应用显示「仅应用内计时」提示。
- [ ] 秒表长时运行与切后台再回来：时间连续、无跳变。

### 2.4 指南针（第 21 节）
- [ ] **方向约定**：顶部朝北/朝东各一次 → 应显示约 `0°`/`90°`，方向名「北」/「东」，盘面 `N` 转到顶部三角。若实际相反，回来告诉我，我按真机反号。
- [ ] 慢转一圈指针连续、快速转身平滑追上（359°→1° 不绕过 180°）。
- [ ] 立起设备 → 出现「请尽量放平设备」提示，读数仍显示；放平后消失。
- [ ] 靠近磁源读数漂移，按提示画「8」字后恢复稳定。
- [ ] 无磁力计设备/权限失败时显示「读不到方向传感器」，**不得显示 0.0°/北**。
- [ ] 权限列表仍为 3 项（`PUBLISH_AGENT_REMINDER`/`DETECT_GESTURE`/`ACCELEROMETER`）。

### 2.5 语言跟随系统（第 23 节）
- [ ] 系统语言切成 English，应用语言选「跟随系统」→ 界面为英文；切回中文 → 回到中文。
- [ ] 系统语言变化后回到前台（不杀进程）再进设置页，界面应已跟随。
- [ ] 覆盖安装（保留旧的 `zh`/`en` 偏好）：升级后语言与升级前一致。
- [ ] 全新安装首次进设置页：语言为「跟随系统」。

### 2.6 扫码 / 条码成像（第 11 / 12 / 14 节）
- [ ] 真机相机扫 WiFi 二维码能直接连网、扫名片二维码能存联系人。
- [ ] 12 种码制（含 Data Matrix/PDF417/Aztec）生成的图能被另一台设备扫出来；UPC-E / ITF-14 校验位正确。
- [ ] 保存到相册、系统分享面板、取消扫描后的提示文案。

### 2.7 文档扫描 / 水平仪 / 手电筒（发布检查表相应段落）
- [ ] 文档扫描：拍摄纸张的自动裁切效果、JPG/PDF 导出、保存到相册、分享完成动作。
- [ ] 水平仪：不同姿态（平放/侧立/倾斜）读数与气泡、退后台再回来仍订阅。
- [ ] 手电筒：开关切换、离开页自动关闭、无闪光灯设备的提示。

### 2.8 沉浸材质（第 4 / 25 节）
- [ ] 内容区卡片在真机上是否透出光感（输入框、结果卡）；不支持材质的机器退化为纯色底且对比度足够。
- [ ] 输入框在真机材质下的观感：不再自带灰底盖住材质（本轮已把 24 个输入类组件改成透明底）。

### 2.9 智感握姿（发布检查表相应段落）
- [ ] 左手、右手、双手/未知、权限不足或设备不支持四种情形下的操作行位置（默认靠稳定侧，宽屏不移动）。

### 2.10 平板 / 阔直板 / 阔折叠 / 三折叠（第 5 / 27 节）
- [ ] 选项行（日期方式、单位类别/从/到/精度、条码码制、个税、设置语言）在 707 / 1107 / 1440 vp 下标签不截断、下拉占满余宽。
- [ ] 结果卡与卡片网格在宽屏下按断点居中（MD 及以下 920 vp、LG 1080 vp、XL 1200 vp）、文字不被拉伸；工具网格列数应为 2（376–440 vp）/ 3（600–840 vp）/ 4（840–1440 vp）/ 5（≥1440 vp），越界与异常见第 27 节实测表。
- [ ] 展开/折叠（含三折叠的 `single`/`double`/`triple` 三种状态）时**不重启应用**应即时重排；悬停（半折）姿态下不出现控件重叠。
- [ ] 阔折叠 3.5" 方形外屏（约 327×327 vp）：首屏只有「搜索框 + 1 张卡片」，搜索框占位符为短文案「搜索工具」；确认这种极窄形态的观感是否可接受（搜索框/标题栏占去约 195 vp 属固有限制）。
