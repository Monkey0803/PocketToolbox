# 真机验收清单（一页版，可勾选）

> 用途：把**还没在真机上跑过**的验收项集中到一页，插上 PLR-AL00（或同形态真机）后按顺序走一遍，通过就打勾。
> 逐条步骤与更细的现象描述仍在 [`DEVICE_ACCEPTANCE.md`](DEVICE_ACCEPTANCE.md)（每项后面标注了章节号）。
> 模拟器能做的（交互、刷新、文案、坐标）都已在 `DEVICE_ACCEPTANCE.md` 里标为「模拟器已通过」，这里只列**必须真机**的项。

## 0. 环境与命令

```powershell
$hdc = "C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe"
$t   = "<真机 key，hdc list targets 里那条非 127.0.0.1:5555 的>"
& $hdc -t $t install -r entry/build/default/outputs/default/entry-default-signed.hap   # 升级安装，保留数据
& $hdc -t $t shell aa force-stop com.example.pockettoolbox
& $hdc -t $t shell aa start -a EntryAbility -b com.example.pockettoolbox --ps tool qr  # 直达某个工具页
& $hdc -t $t shell uitest dumpLayout -p /data/local/tmp/l.json                          # 读控件文本与 bounds
& $hdc -t $t file recv /data/local/tmp/l.json .cache/l.json
& $hdc -t $t shell snapshot_display -f /data/local/tmp/x.jpeg                           # 截图
& $hdc -t $t file recv /data/local/tmp/x.jpeg docs/screenshots/phone/<名字>.jpeg
& $hdc -t $t shell uitest uiInput click <x> <y>                                         # 点按（坐标与截图同尺度）
```

真机 PLR-AL00 的密度是 3x：**48 vp = 143 px、44 vp = 131 px、56 vp = 167 px、144 vp = 428 px**（用 `dumpLayout` 的 `bounds` 反推可点区域是否达标）。

## 联网放开：登记表 + 门控 + 网络查询 + 节气数据包 + 纪念日提醒（2026-10-22）

> 模拟器若没有外网（或网络策略拦住了目标站点），下面「成功路径」无法在模拟器复核——**以夹具单测为准的只是解析与文案**，真实联网必须真机跑。**五条四态口径**：每条联网功能都要跑「成功 / 失败 / 缓存回退 / 开关关闭」四种。

### N1 联网门控（设置页「联网」区块）

### N2 链接信息（网络工具第 5 种方式）
- [ ] **正常网站**：输入 `https://example.com` → 显示标题与描述、跳转 0 次、最终地址与输入一致。
- [ ] **短链**：输入一个真实的短链 → 显示跳转次数与最终地址；**循环跳转的短链应被拦住并如实报错**，不能卡死或显示空。
- [ ] **明文/非法输入**：`http://` 或空输入 → 明确提示只支持 HTTPS / 请先输入，**不发起请求**。
- [ ] **不写历史**：查询后进历史页 → 不应出现链接信息条目。

### N3 网络查询（第 26 个工具）
- [ ] **IP 归属地**：填 `8.8.8.8` → 显示网段、网络名、国家代码、机构等；文案口径是「网段归属」而不是城市定位。

- [ ] **不写历史、不落盘**：三种方式查询后进历史页都无新条目；退出重进页面输入为空。

### N4 节气与农历节日数据包
- [ ] **随包数据**：日期计算 → 农历 → 选一个节气日（如 2026-02-04 立春）→ 显示「节气：立春」；选 2026-02-17 → 显示「传统节日：春节」；**不是节气/节日的日子不显示对应的行**（不是显示占位）。

- [ ] **开启提醒**：纪念日行点铃铛 → 首次应弹系统通知授权；允许后到当天 09:00 收到本地通知（可用「今天」或「明天」的纪念日快速验证）。

- [x] **基本双向结果**：`a b` → 编码 `a%20b`；`%E4%BD%A0%E5%A5%BD` → 解码出 `你好`（中文显示正常）。
- [x] **四种方式的差别**：组件方式把 `:/?=&%` 全部编码（结果与 Node `encodeURIComponent` 逐字符一致）；整串网址**保留** `:/?&=`、空格 → `%20`；表单方式把 `+` 解码成空格、编码时空格写 `+`；「方式」下方那行口径说明随选择变化（四种都看过）。
- [x] **自定义保留字符**：选「自定义」→ 保留字符里输入 `& : %` → 下方「实际保留」显示 `&:`（`%` 与空白被丢掉）；编码结果里 `&` 与 `:` 保持原样、`%` 变成 `%25`。
- [x] **表单方式的 `+` 与空格**：输入 `a+b=c+d&x=%2B` 选「表单」→ 解码 `a b=c d&x=+`；切回「组件」→ 解码仍是 `a+b=c+d&x=+`（`+` 只有表单方式当空格），`%2B` 两种方式下都解成 `+`。
- [x] **非法转义不谎报**：输入里带 `a=%zz` → 解码那一行**只红这一行**并给出「内容不是该编码的合法格式」，**编码结果照常显示**，页面不崩、不静默留空。
