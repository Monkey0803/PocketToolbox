简体中文

随身工具箱不要求注册账号，不集成广告、统计或云同步服务。应用在本机保存二维码生成与扫描历史（最多 50 条）、计时器、秒表状态、工具收藏、语言偏好，以及单位换算上次使用的类别、源单位、目标单位与有效位数（不含你输入的数值）。智感握姿开关（键 hand_posture，值为开启 / 关闭）也保存在本机：它只记住「动作按钮是否随正在操作的手移动」这一项偏好，不保存握姿/手势本身。工具页与收藏页「每行显示几个」（键 tools_columns / favorites_columns，值为 auto 或 1–6）同样保存在本机：它只记住两个页签各自的网格列数偏好，不含任何工具输入或使用记录。工具页的分类筛选（键 tools_category，值为 all 或某个分类 id）同样保存在本机：它只记住你在工具页浏览的是哪一类工具，不含任何工具输入或使用记录。触觉反馈开关（键 haptic_feedback，值为开启 / 关闭）也保存在本机：它只记住「是否发出短震动」这一项偏好，不含任何使用记录；震动只在你操作到以下节点时发出——倒计时结束、水平仪倾角落进所选容差、罗盘对准你锁定的方位。纪念日清单（每条为「名称 + 日期 + 是否每年重复 + 是否开启本地提醒 + 系统返回的提醒编号」，最多 20 条，键 anniversaries）也保存在本机，可在纪念日页面逐条删除；提醒编号只用于取消本机通知，不含任何推送标识。联网偏好（键 net_prefs：总开关、「仅 Wi-Fi」与逐项开关）同样保存在本机：它只记住你允许哪些联网动作，不含任何工具输入或使用记录。上次成功获取的汇率缓存（键 fx_rates，包含汇率表与数据时间，用于单位换算的「货币」类别）同样保存在本机，可在货币类别里点「更新汇率」覆盖。主题色偏好（键 theme_color，值为预设主题 id 或 custom；键 theme_custom_hex，值为你挑的自定义颜色 #RRGGBB）同样保存在本机：它只记住界面强调色这一项外观偏好，不含任何工具输入或使用记录，也不参与任何计算或联网。个税、条形码、计算、日期、进制与位运算、文本对比、文本、随机选择、亲戚称呼和密码的输入与结果仅在当前运行期间保留，不写入应用持久存储；离开密码页会清除本页生成的密码（密码页的三种类型「密码 / PIN 码 / 强度检查」的输入与结果、批量生成的多条密码与强度预估同样不落盘、离开即清空；「强度检查」只在本机内存里按字符构成分析，不查任何泄露数据库、也不上传）。主动复制内容时，内容会进入系统剪贴板。你可以在设置中清空二维码历史；点击工具卡片上的星标可以取消收藏。桌面「常用工具」服务卡片同样只在本机读取你的工具收藏与语言偏好，用来在卡片上显示工具名称；卡片不读取任何输入内容或计算结果，也不新增权限或联网行为——敏感的工具输入（个税、密码、文本等）从不出现在卡片上。卸载应用会删除应用沙箱中的这些数据。世界时钟的城市清单（键 world_clock_cities，只存 Asia/Tokyo 这类城市 id，去重、保序、上限 12）也保存在本机：它只记住你添加了哪些城市，不含任何时间或使用记录。番茄钟的设置与进度（键 pomodoro_state，只存三段时长、当前阶段、阶段结束时刻、暂停剩余、已完成轮次与系统返回的提醒编号）同样保存在本机，可在计时页「重置」清空；提醒编号只用于取消本机通知。图片工具的上次选项（键 image_tool_state，只存格式 / 画质 / 尺寸 / 最长边 / 旋转角 / 是否翻转）同样保存在本机，不含任何图片内容。社保与公积金预设（键 tax_presets，只存你自己保存的预设名字、两个缴费比例与两个可选的缴费基数）同样保存在本机，不含任何收入、工资或税额，可在个税页逐条改名或删除；随包只附一条明确标注「示例（非权威）」的比例示例，请按当地社保与公积金公告核对。金额大写的输入与结果只在当前运行期间保留（复制时进入本机历史记录，可随时在历史页删除）。身份证与银行卡号校验的号码只在本机内存里参与校验：不写入存储、不进入历史记录、不写入日志，页面离开后即丢弃；页面只展示由号码本身推出的生日 / 性别 / 年龄 / 省份参考与卡组织参考，且身份证离线无法判断真伪、卡组织识别也可能不准，界面都如实说明。该页也支持扫描取号：点「拍照识别」走系统相机界面（cameraPicker，不申请相机权限），点「从相册选择」走系统相册选择器（不申请相册权限）；照片只写入应用缓存目录（不写入系统相册），由系统提供的端侧文字识别（Core Vision Kit）在本机把号码挑出来填入输入框，随后应用立即删除这张缓存照片；识别失败的提示与识别文本都不含号码之外的其它内容，照片与识别文本都不上传、不联网、不写入存储。

应用可读取系统识别的握持手与交互手状态，仅用于在本机调整高频按钮位置；该状态不保存（只保存设置页里那枚「智感握姿」开关的偏好值，键 hand_posture），也不发送给开发者。沉浸光感读取设备材质支持情况和材质等级，仅用于选择本机界面效果。

扫码使用系统 Scan Kit 提供的相机和相册界面。应用接收你选择扫描的二维码内容，用于展示和保存本地历史；不会自动打开其中的网址。条形码扫描结果仅在当前运行期间保留。生成的二维码或条形码只有在你主动保存或分享时才交给系统文件选择器或分享面板；条形码也可由你主动保存到系统相册。证件照工具同样只用系统相册选择器选图（不申请相册权限）：你选中的那张照片、以及按规格裁剪、换底色、拼到相纸上的全部像素处理都在本机内存里完成，其中「自动构图」用的人脸检测与「换底色」用的主体抠图都是系统提供的端侧能力（Core Vision Kit），不联网、不上传、不写入存储；所选照片的临时授权只在页面打开期间有效，离开页面即释放，生成的证件照也只在你主动保存到相册或分享时才交给系统。为二维码选择居中 Logo 时同样使用系统相册选择器（不申请相册权限）：这张图片只在本机内存里参与合成、贴在生成的二维码上，不保存、不上传，离开二维码页面即释放。文档扫描使用系统扫描控件处理你拍摄或选择的图片，返回的文件 URI 仅在当前运行期间保留；只有你主动导出、主动保存到相册、在结果页点「分享」，或直接在系统控件中分享时才交给所选目标（结果页分享时应用会先把这些扫描件复制到自己的缓存目录，分享面板关闭后立即删除）。扫描后可以点「提取文字」：文字识别由系统提供的端侧能力（Core Vision Kit）在本机完成，图片与识别文本都不上传、不联网、不写入存储；识别文本只在你主动复制、送入文本工具（进入本机历史，历史同样只存在本机、可随时在历史页删除）或导出为 .txt 时离开本页，导出文件由你在系统保存器里选择位置。另外，在结果页点「重新编辑」会把当前页交回系统扫描控件继续编辑，同样不出本机。本机数据导出同样只在你主动点击并确认后进行：设置页的「导出本机数据」会让上面列出的本机数据（历史、收藏及顺序、计时器与秒表、纪念日、汇率缓存、单位与语言偏好、工具与收藏页每行显示几个、工具页分类筛选）打包成一个 JSON 文件，历史页的「导出记录」会生成一份纯文本，两者都由你在系统保存器里选择位置，不会上传到任何服务器；导出后的文件由你自行保管与删除。水平仪仅在该页面打开时读取加速度传感器以显示倾角，离开页面或应用退后台时停止读取，不保存测量数据。指南针仅在该页面打开时读取方向（磁力计/方向）传感器以显示方位角，同样在离开页面或应用退后台时停止读取、不保存读数，且不需要申请任何权限。手电筒仅在你主动开启时使用设备闪光灯（常亮、求援灯语、摩尔斯灯语、频闪都只在页面内发送，闪烁节奏在本机计算），离开页面或应用进入后台时一律关闭。屏幕补光是把屏幕当作光源的界面功能：进入时把当前窗口亮度调到最高、退出时恢复系统亮度；「保持屏幕常亮」也由你的开关控制，且屏幕补光模式下强制保持常亮，以免屏幕休眠让补光失效。这些设置只作用于本机界面，不申请任何权限、不写入本地存储、也不上传。倒计时在你启动后申请系统通知授权，并尝试创建系统代理提醒；授权被拒绝时，界面会说明后台提醒不可用。当你在别的应用里分享文本或链接并选择「随身工具箱」时，应用只在本次分享会话内读取这段文字（用于生成二维码、用文本工具处理或复制），既不写入本机存储也不上传，关闭分享界面即清除；图片、文件等非文字内容不读取。图片工具同样只用系统相册选择器选一张图（不申请相册权限）：解码、缩放、旋转翻转与重新编码全部在本机内存里完成，原图与结果都只在本机缓存里短暂存在，不上传、不写入应用数据、不进入历史记录；只有你主动点「保存到相册」或「分享」时，结果图才交给系统相册或分享面板（分享前会先落到应用缓存目录，面板关闭即删）。触觉反馈只在倒计时结束、水平仪到位、指南针对准锁定方位这三个节点发出一次短震动（可在设置页关闭；本机只保存开关值，键 haptic_feedback，不记录任何使用历史）。

个税计算在本机完成，不向开发者或第三方发送工资、社保、公积金及扣除输入。只有你主动点击页面中的官方规则或查询链接时，系统才会打开对应外部网站；网站会按自身政策处理访问数据。应用本身不向开发者服务器发送上述数据。你通过系统分享面板选择第三方应用，或主动打开扫码网址后，数据处理遵循对应服务的政策。

农历换算与工作日统计完全离线完成：农历、干支与生肖由设备上的系统历法推算；工作日与调休统计使用随应用发布的节假日日历文件（数据来源与许可见 THIRD_PARTY_NOTICES.md）。离线工具完整可用：节假日日历、农历、二维码/条形码、个税、换算（除货币汇率需在更新后使用缓存）、日期、文本、随机、密码、计时、手电筒与水平仪等全部功能都不依赖网络。

权限：应用共申请 6 项权限（与上一版相同，本次联网能力扩展没有新增任何权限），全部只用于本机功能或你主动触发的联网动作——

  • ohos.permission.PUBLISH_AGENT_REMINDER：倒计时到期、纪念日到当天 09:00 时创建系统代理提醒（本地通知，不需要联网）。
  • ohos.permission.DETECT_GESTURE：读取系统识别的握持手与交互手状态，仅用于本机界面适配。
  • ohos.permission.ACCELEROMETER：水平仪页面读取加速度传感器显示倾角。
  • ohos.permission.VIBRATE：在你操作到上文所列的三个节点时发出一次短震动；可在设置页关闭，关闭后一次都不震。
  • ohos.permission.INTERNET：在你显式触发下面各项联网动作时发起 HTTPS 请求。
  • ohos.permission.GET_NETWORK_INFO：用于网络工具的 DNS 域名解析（connection.getAddressesByName）与「仅 Wi-Fi」选项判断当前网络类型（Wi-Fi / 以太网 / 蜂窝）；应用不读取 Wi-Fi 名称、不读取蜂窝网络标识，也不把网络状态用于其它目的。

联网动作全部登记在应用内、逐项可关，且全部由你显式触发、离线优先。设置页的「联网」区块列出下面每一项，各自有独立开关；总开关可以一次关闭所有联网动作（关掉后任何联网动作都不会发起请求，界面会说明原因而不是「点了没反应」），另有「仅 Wi-Fi」选项（打开后只在 Wi-Fi 或以太网下联网；判断不出当前网络类型时也不发起请求，并如实提示）。这些动作是：

  1. 网络工具：你在页面里输入主机 / 网址 / 端口并点击按钮后，才会发起 DNS 解析（connection.getAddressesByName）、TCP 端口连通探测，或 HTTPS 请求（读取状态码与响应头，可选跟随重定向）。请求目标只在该次请求期间使用，不写入历史、不落盘、也不上传任何其它内容；其中「网址分解」方式完全离线完成，不需要网络。请求失败统一给出中英文错误原因，不会静默重试。
  2. 链接信息（含短链展开）：你输入一个 https:// 网址并点击后，应用会请求该网址（自己按 Location 响应头最多跟随 5 次跳转，以便展开短链），读取并展示网页标题、描述与站点名，以及跳转次数与最终地址。发送出去的只有你输入的那个网址（以及跳转过程中目标网站要求的常规请求头）；结果不落盘、不写历史。
  3. 网络查询 —— IP 归属地与域名 WHOIS：你输入一个 IP 或域名并点击后，应用向公开的域名注册信息查询服务 RDAP（引导服务 https://rdap.org/，会跳转到该 IP/域名的权威服务器）查询注册信息（网段起止与所属机构，或域名注册商、注册/到期时间、DNS 服务器等）。发送出去的只有你输入的那个 IP 或域名；结果不落盘、不写历史。本应用不使用 IP 地理定位服务，因此「归属地」给的是注册机构与网段，不是城市级位置；未注册的目标会如实显示「没有查到注册信息」。
  4. 网络查询 —— TLS 证书查看：你输入一个主机（可带端口）并点击后，应用与该主机做一次 TLS 握手并读取它的服务器证书（主题、颁发者、有效期、序列号、SAN，以及协商出的协议版本与密码套件）。为如实回答「系统信不信任它」，应用会做两次握手：一次用系统 CA 正常校验、一次跳过校验把证书内容读出来；两次结果分开显示，不会把「读到了内容」说成「证书可信」。除了 TLS 握手本身，应用不发送任何内容；证书内容不落盘、不写历史。
  5. 单位换算的「货币」类别：只有你点「更新汇率」时才向公开汇率接口请求一次；发送的内容只有基准货币代码（例如 CNY）。结果保存在本机（键 fx_rates，含数据时间）；失败时不会覆盖缓存，界面继续用上次成功获取的汇率并标注这份数据的时间。没有缓存时明确提示「还没有可用的汇率」，不会显示 0。删除方式：再次成功更新即覆盖，或在系统设置中清除应用数据/卸载应用。
  6. 设置页的「节假日数据」更新：只有你点「检查更新」时才拉取公开的节假日 ICS 文件，不发送任何用户数据；校验失败或网络失败一律保留随包数据，不会用坏数据覆盖。
  7. 设置页的「节气与农历节日」数据包更新：只有你点更新按钮时才拉取公开的节气与农历节日数据包（数据由 MIT 许可的历算库在构建期生成，见 THIRD_PARTY_NOTICES.md），不发送任何用户数据；校验失败或网络失败一律保留随包数据。该数据包地址尚未定稿时按钮会如实提示「尚未配置」，不会发起请求。
  8. 应用内更新检查：只有你点「检查更新」时才读取一份公开的版本清单并与本机版本比较，不发送任何内容；清单地址尚未定稿时同样如实提示、不发起请求。

联网偏好（键 net_prefs，内容是总开关、「仅 Wi-Fi」与逐项开关）保存在本机，只用于决定「这次要不要联网」，不含任何工具输入或使用记录。设置页的「清除联网缓存」会删除本机保存的汇率快照、节气数据包与下载的节假日数据（操作前有确认框；删除后需要重新联网获取，随包数据不受影响）。

纪念日与倒计时的提醒：倒计时到期、纪念日到当天 09:00 时，应用通过系统代理提醒 / 本地通知发出提醒（reminderAgentManager + notificationManager）。这完全在本机完成、不需要联网、不新增权限；应用只在本机保存「哪些纪念日开了提醒」与系统返回的提醒编号，不保存任何推送标识。首次使用时系统会询问通知权限，拒绝后界面会如实说明提醒无法生效。

服务卡片进程、应用启动、退到后台、分享扩展都不发起任何网络请求，也不做静默重试；除上述动作之外，应用不收集、不上传使用数据，不集成广告、统计或云同步。请求内容只包含币种代码、公开数据 URL、你主动填写的探测目标（主机 / 网址 / IP / 域名），因此与上述承诺不冲突。

本政策全文随应用一起提供：在设置页「关于」里点「隐私政策全文（离线可读）」即可展开阅读，不需要联网，与本文内容一致；公网地址只是同一份正文的在线版本（可分享给他人），未托管或打不开时不影响你在应用内读到它。

English

Pocket Toolbox requires no account and includes no ads, analytics, or cloud sync. It stores QR creation and scan history (up to 50 entries), timers, stopwatch state, tool favorites, language preference, and the converter's last category, source unit, target unit and significant digits (never the value you typed). The adaptive hand posture switch (key hand_posture, on or off) is stored on this device too: it only remembers whether action buttons follow the hand operating the phone, and never stores the hand or gesture itself. The per-row setting of the tools and favourites tabs (keys tools_columns / favorites_columns, auto or 1–6) is stored on this device as well: it only remembers how many grid columns each of those two tabs uses, and contains no tool input or usage record. The tools tab's category filter (key tools_category, all or a category id) is stored on this device too: it only remembers which category of tools you were browsing, and contains no tool input or usage record. The haptic feedback switch (key haptic_feedback, on or off) is stored on this device too: it only remembers whether short vibrations are allowed, and contains no usage record; a vibration is sent only when a countdown finishes, when the spirit level's tilt falls within the chosen tolerance, and when the compass aligns with a bearing you locked. An anniversary list (name + date + whether it repeats yearly + whether a local reminder is enabled + the system reminder identifier, up to 20 entries, key anniversaries) is also kept on this device and can be deleted entry by entry on the anniversaries page; the identifier is only used to cancel a local notification and contains no push token. The networking preferences (key net_prefs: the master switch, Wi-Fi-only and the per-action switches) are kept on this device too: they only remember which network actions you allow, and contain no tool input or usage record. The last successfully fetched exchange-rate cache (key fx_rates, holding the rate table and its data time, used by the converter's Currency category) is kept on this device too and is overwritten whenever you tap Update rates. Income tax, barcode, calculator, date, base & bitwise, text diff, text, random picker, kinship and password inputs and results remain in memory only while the app runs; leaving the password page clears its generated password (the password page's three types (Password, PIN and Strength check) with all their inputs and results — including the extra passwords of a batch and the strength estimate — are likewise never written to storage and are cleared on leaving; Strength check analyses the password in memory on this device only, queries no breach database and uploads nothing). Copying content places it on the system clipboard. You can delete individual QR entries or clear the history in Settings, and remove favorites with the star on each tool card. The home-screen "Quick tools" widget likewise reads only your locally stored tool favorites and language preference to label its tiles; it never reads typed input or results, and it adds no permission and no network access — sensitive inputs (income tax, passwords, text, …) never appear on the widget. Uninstalling the app removes its sandbox data. The world clock city list (key world_clock_cities, storing only city ids such as Asia/Tokyo, de-duplicated and capped at 12) is kept on this device too: it only remembers which cities you added and contains no times or usage record. The Pomodoro settings and progress (key pomodoro_state: the three durations, the current phase, the phase end time, the paused remainder, completed rounds and the system reminder identifier) are kept on this device as well and can be cleared with Reset on the timers page; the identifier only cancels a local notification. The image tool's last options (key image_tool_state: format, quality, size, max edge, rotation and flips) are kept on this device too and contain no image content at all. The social-insurance and housing-fund presets (key tax_presets: only the preset names you saved, two contribution rates and two optional contribution bases) are kept on this device and contain no income, wage or tax figures; you can rename or delete them one by one on the tax page. A single example marked "example (not authoritative)" ships with the app — check it against your local social-insurance and housing-fund announcements. Amount in words keeps its input and result for the current run only (a copy goes into local history, deletable from the history page). ID card and bank card numbers are checked in memory only: never written to storage, never added to history, never logged, and discarded when you leave the page; the page only shows the birth date, gender, age, province and card network derived from the number, and it states clearly that an ID number cannot be verified offline and that the card network is a best-effort guess. That page can also read the number from a photo: “Take photo” opens the system camera UI (cameraPicker, no camera permission is requested) and “Choose image” opens the system photo picker (no gallery permission); the photo is written only to the app cache directory (never to the gallery), on-device text recognition (Core Vision Kit) picks the number out and fills it in, and the app deletes that cached photo immediately afterwards. The photo and the recognised text are never uploaded, never sent over the network and never written to storage.

The app may read the hand holding or operating the device to place frequent controls within easier reach. This status is used on the device only and is neither stored (only the adaptive hand posture switch itself is remembered, key hand_posture) nor sent to the developer. It also reads the device's material support and level to choose a local visual effect.

QR and barcode scanning use the system Scan Kit camera and gallery interface. The app receives the QR content you choose to scan to show it and store local history; it does not open URLs automatically. Barcode scan results remain in memory only. A generated QR or barcode image leaves the app only when you choose Save or Share; you can also choose to save a barcode to the system gallery. The ID photo tool also uses only the system gallery picker (no gallery permission): the photo you pick, and all pixel work (cropping to the chosen size, background replacement and sheet layout) happen in on-device memory, where face detection for auto framing and subject cut-out for background replacement are on-device system capabilities (Core Vision Kit) that never go online, never upload and are never written to storage; the picker's temporary permission lasts only while the page is open and is released when you leave, and a generated ID photo leaves the app only when you save it to the gallery or share it. Document scanning uses the system control to process photos you capture or select. Returned file URIs remain in memory until you export or share from the system control. The spirit level reads the accelerometer only while its page is open, stops when you leave or background the app, and does not store measurements. The compass reads the direction (magnetometer/orientation) sensor only while its page is open, stops when you leave or background the app, does not store readings, and requires no permission. The flashlight uses the device light only when you turn it on (steady light, rescue signals, Morse light and strobe are all sent from the page, with the timing computed on your device) and turns it off when you leave the page or the app enters the background. Screen light turns the screen itself into a light source: entering it raises the current window brightness to maximum and exiting restores the system brightness, and "Keep screen on" follows your switch (screen light always keeps the screen on so the light cannot be interrupted by screen-off). These settings affect only the local interface, require no permission, are not written to local storage and are never uploaded. When you start a countdown, the app asks for notification access and attempts to create a system reminder; if unavailable, the interface says background alerts are unavailable. When you share text or a link from another app and choose Pocket Toolbox, the app reads that text only for the current share session (to create a QR code, open it in the text tools, or copy it); it is neither written to local storage nor uploaded, and it is cleared when the share sheet is closed. Images, files and other non-text content are not read. The image tool likewise uses only the system gallery picker for a single image (no gallery permission): decoding, scaling, rotation/flipping and re-encoding all happen in on-device memory, the original and the result exist only briefly in the app cache, and nothing is uploaded, written to app data or added to history; the result image leaves the app only when you tap Save to gallery or Share (sharing first stages a copy in the app cache directory and deletes it when the panel closes). Haptic feedback sends one short vibration at three moments only — a countdown finishing, the spirit level reaching level, and the compass aligning with a locked bearing (it can be switched off in Settings; only the switch value is stored, key haptic_feedback, with no usage history).

Income tax is calculated on your device; wage, social insurance, housing fund, and deduction inputs are not sent to the developer or a third party. Only when you tap an official reference or query link does the system open that external website, which handles visit data under its own policy. The app itself does not send this data to a developer server. If you choose another app from the system share sheet or open a scanned URL, that service's privacy policy applies.

Lunar date conversion and working-day counts are fully offline: the lunar date, sexagenary cycle and zodiac are computed by the system calendar on your device, and working-day, holiday and make-up workday counts use the holiday calendar file shipped with the app (source and licence: THIRD_PARTY_NOTICES.md). The offline tools remain fully usable: the bundled holiday calendar, lunar dates, QR and barcodes, income tax, conversion (except currency rates, which need a cache after an update), dates, text, random, passwords, timers, flashlight and spirit level all work without a network.

Permissions. The app requests six permissions (unchanged by this networking expansion — no new permission was added), all of them for a local feature or for a network action you trigger yourself:

  • ohos.permission.PUBLISH_AGENT_REMINDER — create a system reminder when a countdown expires and at 09:00 on an anniversary you enabled a reminder for (a local notification; no network).
  • ohos.permission.DETECT_GESTURE — read the system's holding/operating hand for local layout adaptation only.
  • ohos.permission.ACCELEROMETER — read the accelerometer on the spirit level page to show the tilt.
  • ohos.permission.VIBRATE — give one short vibration at the three moments listed above; you can turn it off in Settings, and nothing vibrates once it is off.
  • ohos.permission.INTERNET — make HTTPS requests when you explicitly trigger the network actions below.
  • ohos.permission.GET_NETWORK_INFO — used for DNS resolution in the Network tools (connection.getAddressesByName) and for the Wi-Fi-only option to tell which kind of network is in use (Wi-Fi / Ethernet / cellular); the app does not read the Wi-Fi name, does not read cellular identifiers, and does not use network state for anything else.

Every network action is listed in the app (Settings → Networking) with its own switch, and each is user-triggered and offline-first. The master switch turns them all off at once — when it is off nothing is requested and the screen says so rather than doing nothing. A Wi-Fi-only option makes the app go online only on Wi-Fi or Ethernet, and if the current network type cannot be determined nothing is sent (the app says so). The actions are:

  1. Network tools: only after you type a host / URL / port and tap a button does the app perform a DNS lookup (connection.getAddressesByName), a TCP port connectivity probe, or an HTTPS request (reading the status code and response headers, optionally following redirects). The target you type is used only for that request — it is not written to history, not stored, and no other content is uploaded; the "URL parts" mode is entirely offline and needs no network. Failures report a bilingual reason and are never retried silently.
  2. Link info (including short-link expansion): after you enter an https:// address and tap, the app requests that address (following up to five Location redirects itself so that short links can be expanded) and shows the page title, description and site name, plus the number of hops and the final address. What leaves the device is the address you typed (plus the ordinary request headers the destination requires); the result is not stored and not written to history.
  3. Network lookup — IP information and domain WHOIS: after you enter an IP address or domain and tap, the app queries the public registration data service RDAP (the bootstrap service https://rdap.org/, which redirects to the authoritative server for that IP/domain) for registration data — the network range and organisation, or the registrar, registration/expiry dates and nameservers. What leaves the device is the IP address or domain you typed; the result is not stored and not written to history. The app does not use an IP geolocation service, so "location" here means the registration organisation and network block, not a city; an unregistered target is reported honestly as "no registration record found".
  4. Network lookup — TLS certificate: after you enter a host (optionally with a port) and tap, the app performs a TLS handshake and reads that server's certificate (subject, issuer, validity, serial number, SANs, and the negotiated protocol version and cipher suite). To answer "does the system trust it" honestly it performs two handshakes: one with normal system-CA validation, one with validation skipped so the certificate can be read either way; the two results are shown separately and the app never presents "the contents were read" as "the certificate is trusted". Apart from the handshake itself nothing is sent, and the certificate contents are not stored.
  5. The converter's Currency category: only when you tap Update rates does the app request a public exchange-rate endpoint once, sending nothing but the base currency code (e.g. CNY). The result is cached on this device (key fx_rates, including its data time); a failure never overwrites the cache, and the app keeps using the rates from the last successful fetch, labelled with that data's time. With no cache it says clearly that no rates are available instead of showing 0. To remove it: a later successful update overwrites it, or clear the app's data / uninstall the app in system settings.
  6. The Settings page's holiday data update: only when you tap Check for updates does the app fetch the public holiday ICS file, sending no user data at all; if validation or the network fails it always keeps the bundled data and never overwrites it with bad data.
  7. The Settings page's solar-term and lunar-festival data pack update: only when you tap the update button does the app fetch the public data pack (generated at build time with an MIT-licensed calendar library, see THIRD_PARTY_NOTICES.md), sending no user data at all; if validation or the network fails it always keeps the bundled data. While the pack address has not been finalised the button says so honestly and makes no request.
  8. The in-app update check: only when you tap Check for updates does the app read a public version manifest and compare it with the installed version, sending nothing at all; while the manifest address has not been finalised it says so honestly and makes no request.

The networking preferences (key net_prefs: the master switch, Wi-Fi-only and the per-action switches) are kept on this device and only decide whether a given action may go online; they contain no tool input and no usage record. Settings' Clear network cache deletes the on-device rate snapshot, solar-term data pack and downloaded holiday data behind a confirmation dialog; they then have to be fetched again, and the bundled data is unaffected.

Anniversary and countdown reminders: when a countdown expires, or at 09:00 on an anniversary for which you enabled a reminder, the app raises it through the system's reminder agent / local notifications (reminderAgentManager + notificationManager). This happens entirely on the device, needs no network and adds no permission; the app only stores, on this device, which anniversaries have reminders enabled and the reminder identifiers the system returned — no push token of any kind. The system asks for notification permission the first time, and if it is refused the screen explains that the reminder cannot fire.

The widget process, app start-up, returning to the background and the share extension make no network requests, and there are no silent retries. Beyond the actions above the app collects and uploads no usage data and includes no ads, analytics or cloud sync. Those requests carry only a currency code, a public data URL and the probe target you typed yourself (a host, address, IP or domain), so they do not conflict with that promise.

The public URL is only the online copy of the same text (handy for sharing); if it is not hosted yet or fails to open, you can still read the policy inside the app.
