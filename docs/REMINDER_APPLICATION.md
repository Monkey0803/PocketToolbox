# 代理提醒权益申请材料草案

申请对象：华为 Background Tasks Kit 的 `ohos.permission.PUBLISH_AGENT_REMINDER` 代理提醒权益。提交前填写正式包名、开发者主体、联系人及 AppGallery Connect 应用信息，按官方当前申请入口或邮件要求发送。当前文档不代表权益已经开通。

**应用名称**：随身工具箱 / Pocket Toolbox

**场景**：用户主动创建并启动一组或多组命名倒计时。用户离开应用或进程终止后，到期时仍需按用户设定的时间收到提醒。应用不使用此能力发送营销、广告或无关消息。

**触发与取消**：用户点击“开始/继续”时建立倒计时代理提醒；暂停、重置、删除时取消对应系统提醒；再次开始时按剩余时间重新建立提醒。单应用最多 30 组，界面限制最多 30 个计时器。

**用户控制**：首次启动计时器时请求通知授权；未授权或权益未开通时清楚显示“仅应用内计时，后台提醒未启用”。用户可随时暂停、重置或删除计时器。

**验证计划**：权益开通后，在签名真机包上分别验证前台、后台、锁屏、进程结束、暂停/重置/删除以及通知授权拒绝的行为，并记录通知截图和系统版本。

参考：[华为代理提醒文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V5/agent-powered-reminder-V5)。
