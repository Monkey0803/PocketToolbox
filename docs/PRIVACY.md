## English

Pocket Toolbox requires no account and includes no ads, analytics, or cloud sync. It stores QR creation and scan history (up to 50 entries), timers, stopwatch state, tool favorites, language preference, and the converter's last category, source unit, target unit and significant digits (never the value you typed). The **adaptive hand posture switch** (key `hand_posture`, on or off) is stored on this device too: it only remembers whether action buttons follow the hand operating the phone, and **never stores the hand or gesture itself**. The **per-row setting of the tools and favourites tabs** (keys `tools_columns` / `favorites_columns`, `auto` or `1`–`6`) is stored on this device as well: it only remembers how many grid columns each of those two tabs uses, and contains no tool input or usage record. The **tools tab's category filter** (key `tools_category`, `all` or a category id) is stored on this device too: it only remembers which category of tools you were browsing, and contains no tool input or usage record. The **haptic feedback switch** (key `haptic_feedback`, on or off) is stored on this device too: it only remembers whether short vibrations are allowed, and contains no usage record; a vibration is sent only when a countdown finishes, when the spirit level's tilt falls within the chosen tolerance, and when the compass aligns with a bearing you locked. An **anniversary list** (name + date + whether it repeats yearly, up to 20 entries, key `anniversaries`) is also kept on this device and can be deleted entry by entry on the anniversaries page. The **last successfully fetched exchange-rate cache** (key `fx_rates`, holding the rate table and its data time, used by the converter's Currency category) is kept on this device too and is overwritten whenever you tap Update rates. Income tax, barcode, calculator, date, **base & bitwise**, **text diff**, text, random picker, kinship and password inputs and results remain in memory only while the app runs; leaving the password page clears its generated password (the password page's **three types (Password, PIN and Strength check) with all their inputs and results — including the extra passwords of a batch and the strength estimate — are likewise never written to storage and are cleared on leaving; Strength check analyses the password in memory on this device only, queries no breach database and uploads nothing**). Copying content places it on the system clipboard. You can delete individual QR entries or clear the history in Settings, and remove favorites with the star on each tool card. The home-screen "Quick tools" widget likewise reads only your locally stored **tool favorites and language preference** to label its tiles; it never reads typed input or results, and it adds no permission and no network access — sensitive inputs (income tax, passwords, text, …) never appear on the widget. Uninstalling the app removes its sandbox data.

The app may read the hand holding or operating the device to place frequent controls within easier reach. This status is used on the device only and is neither stored (only the **adaptive hand posture switch itself** is remembered, key `hand_posture`) nor sent to the developer. It also reads the device's material support and level to choose a local visual effect.

QR and barcode scanning use the system Scan Kit camera and gallery interface. The app receives the QR content you choose to scan to show it and store local history; it does not open URLs automatically. Barcode scan results remain in memory only. A generated QR or barcode image leaves the app only when you choose Save or Share; you can also choose to save a barcode to the system gallery. **The ID photo tool** also uses only the system gallery picker (no gallery permission): the photo you pick, and all pixel work (cropping to the chosen size, background replacement and sheet layout) happen in on-device memory, where face detection for auto framing and subject cut-out for background replacement are on-device system capabilities (Core Vision Kit) that never go online, never upload and are never written to storage; the picker's temporary permission lasts only while the page is open and is released when you leave, and a generated ID photo leaves the app only when you save it to the gallery or share it. Document scanning uses the system control to process photos you capture or select. Returned file URIs remain in memory until you export or share from the system control. The spirit level reads the accelerometer only while its page is open, stops when you leave or background the app, and does not store measurements. The compass reads the direction (magnetometer/orientation) sensor only while its page is open, stops when you leave or background the app, does not store readings, and requires no permission. The flashlight uses the device light only when you turn it on (steady light, rescue signals, Morse light and strobe are all sent from the page, with the timing computed on your device) and turns it off when you leave the page or the app enters the background. Screen light turns the screen itself into a light source: entering it raises the current window brightness to maximum and exiting restores the system brightness, and "Keep screen on" follows your switch (screen light always keeps the screen on so the light cannot be interrupted by screen-off). These settings affect only the local interface, require no permission, are not written to local storage and are never uploaded. When you start a countdown, the app asks for notification access and attempts to create a system reminder; if unavailable, the interface says background alerts are unavailable. **When you share text or a link from another app and choose Pocket Toolbox**, the app reads that text only for the current share session (to create a QR code, open it in the text tools, or copy it); it is neither written to local storage nor uploaded, and it is cleared when the share sheet is closed. Images, files and other non-text content are not read. **Haptic feedback** sends one short vibration at three moments only — a countdown finishing, the spirit level reaching level, and the compass aligning with a locked bearing (it can be switched off in Settings; only the switch value is stored, key `haptic_feedback`, with no usage history).

Income tax is calculated on your device; wage, social insurance, housing fund, and deduction inputs are not sent to the developer or a third party. Only when you tap an official reference or query link does the system open that external website, which handles visit data under its own policy. The app itself does not send this data to a developer server. If you choose another app from the system share sheet or open a scanned URL, that service's privacy policy applies.

Lunar date conversion and working-day counts are fully offline: the lunar date, sexagenary cycle and zodiac are computed by the system calendar on your device, and working-day, holiday and make-up workday counts use the holiday calendar file shipped with the app (source and licence: [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)). **The offline tools remain fully usable**: the bundled holiday calendar, lunar dates, QR and barcodes, income tax, conversion (except currency rates, which need a cache after an update), dates, text, random, passwords, timers, flashlight and spirit level all work without a network.

**Permissions.** The app requests six permissions, all of them for a local feature or for a network action you trigger yourself:

- `ohos.permission.PUBLISH_AGENT_REMINDER` — create a system reminder when a countdown expires.
- `ohos.permission.DETECT_GESTURE` — read the system's holding/operating hand for local layout adaptation only.
- `ohos.permission.ACCELEROMETER` — read the accelerometer on the spirit level page to show the tilt.
- `ohos.permission.VIBRATE` — give one short vibration at the three moments listed above; you can turn it off in Settings, and nothing vibrates once it is off.
- `ohos.permission.INTERNET` — make HTTPS requests when you explicitly trigger the network actions below.
- `ohos.permission.GET_NETWORK_INFO` — used only for **DNS resolution in the Network tools** (`connection.getAddressesByName`); the app does not read the Wi-Fi name, does not read cellular identifiers, and does not use network state for anything else.

**There are exactly three network actions, all user-triggered and offline-first:**

1. **Network tools**: only after you type a host / URL / port and tap a button does the app perform a DNS lookup (`connection.getAddressesByName`), a TCP port connectivity probe, or an HTTPS request (reading the status code and response headers, optionally following redirects). The target you type is used only for that request — it is **not written to history, not stored, and no other content is uploaded**; the "URL parts" mode is entirely offline and needs no network. Failures report a bilingual reason and are never retried silently.
2. **The converter's Currency category**: only when you tap Update rates does the app request a public exchange-rate endpoint once, sending nothing but the base currency code (e.g. `CNY`). The result is cached on this device (key `fx_rates`, including its data time); a failure never overwrites the cache, and the app keeps using the rates from the last successful fetch, labelled with that data's time. **With no cache it says clearly that no rates are available instead of showing 0**. To remove it: a later successful update overwrites it, or clear the app's data / uninstall the app in system settings.
3. **The Settings page's holiday data update**: only when you tap Check for updates does the app fetch the public holiday ICS file, sending no user data at all; if validation or the network fails it always **keeps the bundled data** and never overwrites it with bad data.

The widget process, app start-up and returning to the background make **no network requests**, and there are no silent retries. Beyond those three actions the app **collects and uploads no usage data** and includes no ads, analytics or cloud sync. Those requests carry only a currency code, a public data URL and the probe target you typed yourself, so they do not conflict with that promise.
