# 真机验收清单（日期工具 / 时间戳 / 计时时长）

本清单覆盖本会话改动过、且**尚未在真机上跑过**的界面。所有条目都来自代码阅读与构建结果，没有一条是设备实测；请按顺序走，不通过的条目记下编号并附截图回给我。

- 目标设备：PLR-AL00（HarmonyOS 7 / API 26），调试签名包。
- 安装：DevEco 直接运行，或 `hdc install entry/build/default/outputs/default/entry-default-signed.hap`（`hdc` 在 DevEco SDK 的 `toolchains` 下）。
- 记录方式：每条写「通过 / 不通过」，不通过时附截图与现象；跨零点、时区这类条目需要改系统设置后再看一次。
- 说明：内容区的卡片按约定就是**退化的普通底色**（ArkUI 组件级材质只在标题栏与底部页签渲染），卡片不是玻璃质感属于预期，不要记为缺陷。

## 1. 日期计算（工具网格 →「日期计算」）

### 1.1 分段入口（本轮从下拉菜单改为分段控件）
- [ ] 进入后顶部是一排 **5 个分段**：间隔 / 推算 / 年龄 / 工作日 / 日历。
  - 预期：一屏内放得下，**文字不截断、不省略号**；切到 English 后是 Interval / Offset / Age / Workdays / Calendar，同样不截断。
- [ ] 分段下方是当前方式的**完整标题**（中文「日期间隔」/ 英文 "Days between dates"）。
- [ ] 逐个点五个分段：内容区随之切换，当前分段保持高亮，高亮只在一个分段上。
- [ ] 切到别的分段再切回来：已输入的日期保留（起始/目标日期是两个方式共享的），单位/开关/偏移量各自独立、不串值。

### 1.2 日期间隔
- [ ] 起始日期、目标日期都是**可点卡片**（日历图标 + 日期文字），点开是系统日期选择器（滚轮），而不是输入框。
- [ ] 在日期选择器里滚到别的月份并确认：**卡片文字立即变成新日期**（这是之前真机发现过「选完不刷新」的复验点，重点看）。
- [ ] 选择器里点取消：卡片保持原值。
- [ ] 结果卡：第一行「相隔 N 天」（第二个日期更早时显示「相隔 N 天（第二个日期更早）」），第二行「X 年 Y 个月 Z 天」；同一天时只显示「同一天」。
- [ ] **倒数日**：把起始日期设成上周、目标日期设成下周 → 结果卡第三行显示「已过去 a 天 · 距目标日期还有 b 天」，且 a + b = 两个日期的总天数。
- [ ] 继续验证：把目标日期设成今天 → 第三行「距目标日期还有 0 天」；把今天排除到区间外（起始和目标都在未来）→ 第三行消失。
- [ ] 跨零点复验：设好区间后让设备过零点（或把系统日期改到第二天再进这个页面）→ 「已过去 / 还有」的天数跟着变。

### 1.3 日期推算（周期推算）
- [ ] 有「单位」下拉（系统 `Select`）：天 / 工作日 / 周 / 月 / 年。
- [ ] 单位选「天」，输入 7 → 结果是起始日期 +7 天；输入 -7 → 早 7 天。
- [ ] 单位选「周」，输入 2 → +14 天。
- [ ] 单位选「月」：起始 1 月 31 日 + 1 月 → **2 月 28（闰年 2 月 29）日**；起始 3 月 31 日 - 1 月 → 2 月 28/29 日（月末夹取，不要出现 3 月 2 日这种溢出）。
- [ ] 单位选「年」：起始 2020-02-29 + 1 年 → 2021-02-28；起始 2026-10-15 - 1 年 → 2025-10-15。
- [ ] 单位选「工作日」：起始周五 + 1 个工作日 → 下周一；起始周四 + 2 个工作日 → 下周一。
- [ ] 输入框占位符随单位变化（「天数…」/「工作日数…」/「周数…」/「月数…」/「年数…」）。
- [ ] 输入 0 → 结果等于起始日期；输入非整数（如 1.5）或超大值 → 结果行显示「请输入有效日期和该单位允许范围内的整数数量」，复制按钮置灰。
- [ ] 结果正确时点复制按钮 → 出现系统 toast「已复制」，粘贴出来是结果日期。

### 1.4 年龄计算
- [ ] 出生日期 1990-05-20、参考日期 2026-10-15 → 「36 周岁」「月龄 436 个月」「共 N 天」。
- [ ] 参考日期改成 2026-05-19（生日前一天）→ 周岁变 35，月龄随之变化。
- [ ] 把出生日期设到参考日期之后 → 显示「出生日期需早于或等于参考日期」，不显示月龄与天数。
- [ ] 参考日期设成出生当天 → 「未满 1 周岁」「月龄 0 个月」「共 0 天」。

### 1.5 工作日
- [ ] 起始 2026-10-15（周四）、目标 2026-10-19（周一）→ 「工作日 3 天」。
- [ ] 关掉「计入起始日期」开关 → 变成「工作日 2 天」；再打开 → 回到 3 天。
- [ ] 第二行显示「自然日 M 天 · 仅排除周六周日，不含法定节假日」。
- [ ] 起始与目标同一天且是工作日：开关打开 → 1 天；关闭 → 0 天。
- [ ] 起始与目标同一天且是周六/周日 → 0 天。
- [ ] 把起始日期设到目标之后（反向选择）→ 天数与正向一致（顺序无关）。

### 1.6 星期与周数
- [ ] 日期 2026-10-15 → 「周四」+「年内第 288 天 · ISO 第 42 周（2026 年）」。
- [ ] 日期 2021-01-01 → 「周五」+「年内第 1 天 · ISO 第 53 周（2020 年）」（跨年周，年份显示 2020 而不是 2021）。
- [ ] 日期 2024-12-30 → 「周一」+「ISO 第 1 周（2025 年）」。
- [ ] 切到 English → 星期显示 Monday…Sunday 完整单词。

### 1.7 语言与无障碍
- [ ] 设置页切到 English 再回到日期页：分段标签、标题、字段标签、开关文案、结果文案、错误提示、无障碍名称全部为英文；切回中文同样完整。
- [ ] 打开 TalkBack/屏幕朗读：日期卡片读作「起始日期，2026-10-15」；分段控件能读出当前选中项。

## 2. 时间戳（新工具）

### 2.1 入口与默认态
- [ ] 工具网格里出现「时间戳」卡片（时钟图标、浅蓝底），位置在「日期计算」之后；英文为 "Timestamp"。
- [ ] 点进后标题栏是「时间戳」/ "Timestamp"，且**首行内容没有被标题栏遮住**（标题栏避让）。
- [ ] 默认输入就是当前**秒级**时间戳，结果卡显示四行：本地时间、UTC 时间（以 Z 结尾）、秒级时间戳、毫秒级时间戳。

### 2.2 时间戳 → 时间
- [ ] 输入 `0` → UTC 时间 `1970-01-01 00:00:00Z`；本地时间在东八区设备上是 `1970-01-01 08:00:00`。
- [ ] 输入 `1750000000` → 秒级与毫秒级分别是 `1750000000` / `1750000000000`，UTC 时间与秒级值自洽。
- [ ] 输入 13 位毫秒值 `1750000000123` → 毫秒级原样显示，秒级为 `1750000000`（向下取整）。
- [ ] 输入 `-86400` → UTC 时间 `1969-12-31 00:00:00Z`。
- [ ] 点「填入当前时间戳」→ 输入框变回当前秒级时间戳，结果同步刷新。

### 2.3 日期时间 → 时间戳
- [ ] 输入 `2026-10-15` → 本地时间补零为 `2026-10-15 00:00:00`。
- [ ] 输入 `2026-10-15 08:30` → 本地时间 `2026-10-15 08:30:00`。
- [ ] 输入 `2026-10-15 08:30:45` → 秒级/毫秒级与本地时间互相自洽（把秒级值再贴回输入框，本地时间应回到同一时刻）。
- [ ] 输入 `2026-10-15T08:30:45Z` → 按 **UTC** 解释（东八区设备上「本地时间」比它大 8 小时）。

### 2.4 错误与边界
- [ ] 清空输入 → 「请输入时间戳或日期时间」。
- [ ] 输入 `abc`、`2026-13-01`、`2025-02-29`、`2026-10-15 25:00:00` → 「无法识别：请用时间戳，或 YYYY-MM-DD HH:mm:ss（末尾 Z 表示 UTC）」。
- [ ] 输入 `999999999999999` → 「超出可表示范围（公元 1–9999 年）」。
- [ ] 输入 `0001-01-01T00:00:00Z` 与 `9999-12-31T23:59:59Z` → 正常显示，不报错、不溢出。

### 2.5 复制与时区
- [ ] 两个复制按钮（秒级行、毫秒级行各一个）→ 点击出现 toast「已复制」，粘贴到记事本核对数值。
- [ ] 把系统时区改成 UTC-5 再回到该页：**秒级/毫秒级时间戳不变**，本地时间随之改变（UTC 行不变）。

## 3. 计时（倒计时时长选择器）

- [ ] 「计时」页 → 新建倒计时：名称为可选输入框，下面是**时长卡片**（显示 00:05:00），没有时分秒三个输入框。
- [ ] 点时长卡片 → 系统时间选择器（时分秒三列滚轮、24 小时制）；确认后卡片立即更新；取消则保持原值。
- [ ] 选 00:00:00 后点添加 → toast「请输入 1 秒至 23 小时 59 分 59 秒的时长，最多 30 组」。
- [ ] 选 23:59:59 → 能添加成功，倒计时显示 23:59:59。
- [ ] 列表里点某个计时器的「编辑」→ 该时长回填到时长卡片，修改后重新添加成功。
- [ ] 开始一个倒计时，退到后台再回来：剩余时间连续、没有跳变或重置。
