## 27. 自适应布局：阔直板 / 阔折叠 / 三折叠 / 平板（2026-10-20）

把「窗口尺寸 → 布局」从 `Index.ets` 里写死的 `360/600/840` 三档与统一 920 vp 内容列，改成纯逻辑
`entry/src/main/ets/model/LayoutAdaptive.ets` 的**官方断点**模型，并把窗口尺寸、折叠形态两条事件接上。

**口径（`layoutMetrics(widthVp, heightVp, widthBand?, heightBand?)`）**

- 宽度断点（官方）：XS < 320、SM 320–600、MD 600–840、LG 840–1440、XL ≥ 1440
  → 网格列数 **1 /（窄幅 < 360 vp 时 1，否则 2）/ 3 / 4 / 5**；
- 高度断点（官方，按**高宽比 = 高 / 宽**）：SM < 0.8（矮而宽）、MD 0.8–1.2（近方）、LG ≥ 1.2（竖长）；
- 内容列最大宽度：MD 及以下 920、LG 1080、XL 1200（原来统一 920——1107 / 1440 vp 下左右各空出两百多 vp）；
- 左右边距：XS 16、SM 20、MD 与 LG 24、XL 32；
- `compact`（**只有高宽比 < 0.8 的「矮而宽」为真**）：顶部留白 20→12、区块间距 16→12、网格间距 12→10、页签底部留白 96→88；

## 24. 折扣与均摊：折扣反推 / 立减 / 百分比扩展 / 加价毛利 + 复制与历史（2026-10-19）

进入「折扣与均摊」，顶部「类型」下拉此时应有 **5 项**：折扣计算 / 折扣反推 / 百分比计算 / 加价与毛利 / 均摊计算（英文 Discount / Reverse discount / Percentage / Markup and margin / Split a bill）。

### 24.1 类型下拉与状态保留
- [ ] 逐项选中五个类型：内容区随之切换；再点开下拉，高亮的仍是当前类型。
- [ ] 每个类型都填一下输入，切走再切回：**已填值保留**（各类型输入状态互不串值）。
- [ ] 每张结果卡右侧都有一个蓝色剪贴板按钮；把某个输入改到非法（例如把折数改成 `11`、把百分比改成空）后，结果变成 `—` 且该按钮**置灰不可点**。

### 24.2 折扣计算（含立减）
- [ ] 原价 `100`、折数 `8`、立减 `0` → 折后价 `80.00`，补充行 `省 20.00 · 等效 8 折`。
- [ ] 立减改成 `10` → 折后价 `70.00`、`省 30.00 · 等效 7 折`（**立减在折扣之后扣**）。
- [ ] 立减改成 `200`（超过折后价）→ 折后价 `0.00`、`省 100.00`（**按 0 计、不出现负数**），底部说明写明券额作废。
- [ ] 原价 `0` → 只显示 `省 0.00`，不显示「等效 X 折」（原价为 0 时无法计算等效折扣）。
- [ ] 折数 `11` → 结果 `—`（10 折以上不是折扣）。

### 24.3 折扣反推
- [ ] 折后价 `80`、折数 `8` → 原价 `100.00`、补充行 `省 20.00`。
- [ ] 折数 `0` → 原价结果 `—`（不能反推）。
- [ ] 原价 `100`、折后价 `75` → 折数 `7.5`、补充行 `省 25%`。
- [ ] 原价 `100`、折后价 `120`（涨价）→ 折数 `12`、补充行 `贵 20%`（**折后价高于原价是合法输入**）。

### 24.4 百分比计算（四块）
- [ ] 求一个数的百分之几：`100` × `20%` → `20`。
- [ ] 求部分占整体的百分比：`25` / `100` → `25%`；整体填 `0` → `—`。
- [ ] 算上增加或减少的百分比：`100` ± `10%` → `120 / 80`，补充行「加后 / 减后」；把 `13%` 代进去应是**精确的** `113 / 87`（不能出现 `112.99999…`）。
- [ ] 从原值到新值变化了百分之几：`100` → `120` → `+20%`；`100` → `80` → `-20%`（带符号）；原值 `0` → `—`。

### 24.5 加价与毛利
- [ ] 成本 `80`、加价率 `25%` → 售价 `100.00`、补充行 `毛利 20.00 · 毛利率 20%`。
- [ ] 成本 `80`、售价 `100` → 毛利率 `20%`、补充行 `加价率 25%`（**两个比率不是同一个数**，界面文案已写明口径）。
- [ ] 成本 `0`（第二块）→ 毛利率 `100%`、补充行显示「成本为 0，加价率不适用」。
- [ ] 成本 `120`、售价 `100`（亏本）→ 毛利率 `-20%`、加价率约 `-16.67%`。

### 24.6 均摊（回归）
- [ ] 总金额 `100`、人数 `3`、小费 `10%` → 合计 `110.00`、`2 人各 36.66，1 人各 36.67` 一类**余分分配**结果（与本次改动前一致）。
- [ ] 人数 `0` 或小费 `101%` → 结果 `—`。

### 24.7 复制与历史
- [ ] 任一点复制按钮：出现复制成功 toast，剪贴板内容是该结果卡的**纯值**（如 `80.00`、`25%`、`8`），不含整句。
- [ ] 打开历史页（二维码页操作行的时钟图标）：出现类别「计算结果」，条目是**带输入上下文的整句**（如 `折扣计算 · 原价 100 × 8 折 − 立减 0 = 80.00（省 20.00）`）。
- [ ] 历史页类别筛选里能选到「计算结果」，搜索该句里的数字能命中；**点该条目不跳转**（与「换算结果」同一口径）。
- [ ] 删除当前筛选结果 / 清空历史：这些条目一并按现有入口删除，不残留。
- [ ] 切换语言到 English 后再复制：历史里的整句是英文，且类型下拉与结果文案都变英文。

### 24.8 搜索与布局
- [ ] 工具搜索里输入 `立减`、`满减`、`优惠券`、`反推`、`毛利率`、`加价` 都能命中「折扣与均摊」。
- [ ] 窄屏下「加价与毛利」「百分比计算」的两列输入行不被撑破成两行、不溢出；深色模式下结果卡与说明文字对比度足够。
- [ ] 宽屏（平板/折叠屏展开）下输入行与结果卡仍按整行宽度铺开、数值不被截断。
